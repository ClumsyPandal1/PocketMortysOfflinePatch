# PocketMortysOfflinePatch

Play the original **Pocket Mortys** campaign on iOS after the official servers shut down.

PocketMortysPatched restores the game's campaign by removing its dependency on the original online services.

A huge thank you to **[PocketMortys100Years](https://github.com/pocketmortys100years/PocketMortys2.0.3-Decompiled)** for releasing the decompiled source code. Without their work, this project would not have been possible. Using that source as a foundation, the remaining issues were fixed and built into a fully working IPA for iOS.
